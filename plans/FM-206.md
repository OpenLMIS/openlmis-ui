# FM-206: Onboarding Tour: Offline Events

(React Joyride, isolated module)

Stacked on FM-205 (PR #155).

## Scope

- **In:**
  - a tour for Offline Events;
  - `data-tour` attributes on existing elements of the page (including the three tab buttons): no new
    wrappers, no other view change;
  - module additions:
    - a step's `select` clicks a tab before the step; the tour survives the address change it makes
      itself, and the user's tab comes back when the tour ends;
    - a step's `legend` shows the statuses it explains as the screen's own badges, so the step reads
      true on an empty list;
    - a step's `column` highlights that column's header and sits beside it in a table; on cards it
      falls back to the list and its anchor.
  - the Physical Inventory tours from FM-204 use them too: the program list gets a Status step with a
    legend and an Actions step; the draft's Count Each Line and Explain Differences steps highlight
    Current Stock and Unaccounted Quantity. A header is found by its text or its label's `title`,
    since some headers hold hidden sizers.
- **Out:**
  - other module changes;
  - per-row controls (Details button, status badge, row menu or card buttons): the steps explain them;
  - the Event Details dialog and its confirmations: opening a dialog ends a tour, so the steps describe
    them.

## Summary

Offline Events gets a Show Guide button. The guide walks through:
- the three tabs: events waiting to send, events refused or needing review, and events recorded;
- Filters and View;
- the events: Details shows each event's lines; a separate step covers the row actions and the Event Details dialog;
- what the Pending Events statuses mean;
- each Synchronization Errors label with its fix: Retry, Copy For Correction or Dismiss for a refusal,
  and It Was Recorded or Send Again when the app could not confirm a send.

Legacy has two pages for this, Pending offline events and Offline synchronization errors, with Remove,
Retry and Dismiss and no statuses. It explains nothing.

Content intent (the shipped English copy is the source of truth):
1. What each tab holds; auto-send once online and signed in; Synced includes marked as recorded, kept 30
   days; counts ignore filters; stored in this browser.
2. Filters: type and the event's own date; kept across tabs.
3. Columns or card details; on cards, the sort too.
4. True over an empty tab: what a row shows, Details lines, the "..." menu (buttons on cards): View
   Details, Remove (unsent: for good; synced: this device only).
5. Pending statuses; Waiting is behind an event that is sending or needs attention.
6. Refused and Stock Changed: label vs full reason in View Details; Retry back to Pending Events; Copy
   For Correction in View Details; Dismiss; Copied For Correction stays until dismissed.
7. Needs Review: unconfirmed send, later events wait; check Stock Cards and Transaction History (need a
   connection); It Was Recorded or Send Again in View Details; fixes work offline; Retry and Send Again
   need the right to send.
8. Synced: recorded or marked as recorded, 30 days; View Details shows the server event ID and document
   number; Remove clears the device entry only.

### Rules

- **No new wrappers:** every anchor goes on an element that already exists, so layouts and tests stay
  as they are (the list keeps its `tabIndex` and `listRef`).
- **No anchors in loading views:** the list anchor exists only in the loaded branch; the busy skeletons
  make the runner wait.
- **Dialogs:** Event Details and confirmations are described, never toured. A mouse click on Show Guide
  with a dialog open only closes the dialog.
- **Offline:** the tour runner is a lazy chunk. The production service worker precaches it; without it
  (dev) the import fails offline and the guide ends silently. To prove the precache, reload offline
  before starting the guide.
- **Status wording:** the Held notice is titled "Offline Event Needs Review"; the copy keeps it apart from
  the Needs Review label.
- **Labels:** use the screen's words per locale (tab names, statuses, Retry, Copy For Correction, It Was
  Recorded, Send Again, Dismiss; View is Vista/Affichage/Ver/عرض). Arabic quotes multi-word labels with
  «».

### Risks

- **No event rights, online, no own events:** the page shows no access; the guide finds no anchors and
  ends after 5 s.
- **Device database read error:** an error notice replaces the list, so steps 4 to 7 are skipped.
- **Uploader during the tour:** if it empties the current page, the page clamp changes the address and
  the tour ends. Rare; accepted.
