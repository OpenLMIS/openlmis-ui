(React Joyride, isolated module)

Stacked on FM-205 (PR #155).

## Scope

- **In:**
  - a tour for Offline Events;
  - `data-tour` attributes on existing elements of the page: no new wrappers, no other view change.
- **Out:**
  - module changes;
  - per-row controls (Details button, status badge, row menu or card buttons): the steps explain them;
  - the Event Details dialog and its confirmations: opening a dialog ends a tour, so the steps describe
    them.

## Summary

Offline Events gets a Show Guide button. The guide walks through:
- the three tabs: events waiting to send, events refused or needing review, and events recorded;
- Filters and View;
- the events: Details shows each event's lines, the row actions and the Event Details dialog;
- what the Pending Events statuses mean;
- each Synchronization Errors label with its fix: Retry, Copy For Correction or Dismiss for a refusal,
  and It Was Recorded or Send Again when the app could not confirm a send.

Legacy has two pages for this, Pending offline events and Offline synchronization errors, with Remove,
Retry and Dismiss and no statuses. It explains nothing.

Content intent:
1. Pending Events wait to send and go by themselves when online; Synchronization Errors were refused or
   need review; Synced were recorded, kept here for 30 days. A number shows how many each tab holds,
   whatever the filters. This list lives in this browser on this device.
2. Filters narrow by Pending Event type and the event's own date (From, To), and stay set across tabs.
3. Columns or card details; on cards, the sort too.
4. True over an empty tab: each event shows its type, date and, where there is room, facility and
   program. Details lists its lines (product, lot, quantity, reason or counterparty, date, VVM and
   comments when present). Its actions open Event Details and, where allowed, Retry, Remove or Dismiss
   (a "..." menu in the table, buttons on cards).
5. Pending Events statuses: Queued waits its turn; Sending is in flight; Waiting is behind an event for
   the same facility and program that needs attention; Held needs attention because access or the
   draft changed.
6. Synchronization Errors labels and fixes: Refused or Stock Changed: Retry sends the same event again,
   Copy For Correction opens it in an editor (archiving edits there), Dismiss clears it. Needs Review:
   the app could not confirm the send; check Stock Cards and Transaction History, then It Was Recorded
   or Send Again (which may record it twice); later events for that facility and program wait.
   Copied For Correction stays until dismissed. Retry and Send Again need the right to send for that
   facility and program; everything else works offline, and only the Stock Card and Transaction History
   links need a connection.

### Rules

- **No new wrappers:** every anchor goes on an element that already exists, so layouts and tests stay
  as they are (the list keeps its `tabIndex` and `listRef`).
- **No anchors in loading views:** the list anchor exists only in the loaded branch; the busy skeletons
  make the runner wait.
- **Dialogs:** with Event Details or a confirmation open, the guide cannot start; they are described,
  never toured. Checked in the browser.
- **Offline:** the tour runner is a lazy chunk. The production service worker precaches it; without it
  (dev) the import fails offline and the guide ends silently. To prove the precache, reload offline
  before starting the guide.
- **Status wording:** the Held notice is titled "Offline Event Needs Review"; the copy keeps it apart from
  the Needs Review label.
- **Labels:** use the screen's words per locale (tab names, statuses, Retry, Copy For Correction, It Was
  Recorded, Send Again, Dismiss; View is Vista/Affichage/Ver/عرض). Arabic quotes multi-word labels with
  «».

### Risks

- **No event rights, online, no own events:** the page shows no access; the guide finds no anchors and
  ends after 5 s.
- **Device database read error:** an error notice replaces the list, so steps 4 to 6 are skipped.
- **Uploader during the tour:** if it empties the current page, the page clamp changes the address and
  the tour ends. Rare; accepted.
