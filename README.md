# OpenLMIS UI

Web frontend for OpenLMIS.

## Quick Start

Requires Node 24 (see `.nvmrc`) and pnpm 12 (pinned via `packageManager` in `package.json`).

```bash
cp .env.example .env
pnpm install
pnpm dev
```

## Architecture

### Data Fetching Pattern

- **TanStack Router** owns the route structure and navigation
- **TanStack Query** manages all server state
- Routes `loader` calls `queryClient.ensureQueryData()` during navigation
- Components use `useSuspenseQuery()` to read cached data
- Data is fetched at the route level, consumed at the component level

```
Route loader (ensureQueryData) → Component (useSuspenseQuery)
```

### Feature-Based Structure

Each feature is self-contained with its own queries, components, and types.

```
src/
  index.tsx                        # Entry point
  globals.css                      # Global styles + Tailwind theme
  route-tree.gen.ts                # Auto-generated by @tanstack/router-plugin, committed, never edit
  integrations/
    axios.ts                       # HTTP client (interceptors for auth/errors)
    i18n.ts                        # i18next setup (ICU, language detection)
    tanstack-query.ts              # QueryClient instance
    tanstack-router.ts             # Router instance + type registration
  messages/
    en.json                        # English translations (flat, sorted keys)
    pl.json                        # Polish translations
  types/
    i18next.d.ts                   # Type-safe translation keys
  routes/
    __root.tsx                     # Root layout + devtools
    index.tsx                      # / → redirects to /dashboard
    (protected)/
      _protected.tsx               # Protected layout (sidebar + auth guard)
      _protected.dashboard.tsx     # /dashboard
      _protected.users.tsx         # /users
  features/
    users/
      api/api.ts                   # HTTP calls (getUsers, getUser)
      api/queries.ts               # Query options (uses api + queryKeys)
      lib/types.ts                 # Feature types
  components/ui/                   # shadcn generated components (not linted)
  hooks/
    use-debounce.ts                # Shared hooks
    use-debounce.test.ts           # Tests next to what they test
  lib/
    config.ts                      # App configuration + supported languages
    constants.ts                   # Shared constants
    key-factory.ts                 # TanStack Query key factory
    types.ts                       # Shared types
    utils.ts                       # Shared utilities (re-exports `cn`)
  tests/
    setup.ts                       # Global test setup only
scripts/
  sort-messages.mjs                # Sorts translation keys alphabetically
```

### Build Optimization

`vite.config.ts` defines `vendorChunks` to split large, stable libraries (React, TanStack) into separate cached chunks. Browsers don't re-download them when only app code changes. Other deps land in the default vendor chunk - splitting small packages costs more (extra HTTP requests) than it saves.

### Linting & Formatting

| Package | Rationale |
|---|---|
| [@biomejs/biome](https://biomejs.dev) | Linter + formatter + import sorter (replaces ESLint + Prettier) |
| [oxlint](https://oxc.rs/docs/guide/usage/linter) | Host for the `@shadcn/lint` plugin, every built-in category disabled |

Configuration in `biome.jsonc`:
- Recommended rules (React hooks, a11y, correctness)
- Auto import sorting
- Tailwind directive support (`@apply`, `@theme`)
- `type` preferred over `interface`
- shadcn `src/components/ui/**` excluded (generated code)
- kebab-case filenames enforced

Configuration in `.oxlintrc.json`: every Oxlint category is off, so `pnpm lint:ds` reports
shadcn rules only and never overlaps Biome. Biome stays the linter and formatter of record;
Oxlint is installed purely because Biome's plugin system accepts GritQL only and cannot load
a JS plugin. All six rules are errors and gate CI. When a page needs a different treatment,
add a variant prop to the component in `src/components/ui/` instead of passing a `className`
override.

## Conventions

- **File naming**: kebab-case (enforced by Biome)
- **Types**: `type` over `interface` (enforced by Biome), always use named `Props` types (e.g. `type UserCardProps = { ... }`)
- **Imports**: Auto-sorted by Biome, always use `@/*` aliases
- **Path aliases**: `@/*` maps to `src/*`
- **Data fetching**: `ensureQueryData` in route loaders, `useSuspenseQuery` in components
- **HTTP**: Use `client` from `@/integrations/axios`, `async/await` over `.then()`
- **Auth**: `beforeLoad` in `_protected.tsx` for route-group-level authentication
- **Tests**: Colocated with source files (`foo.ts` → `foo.test.ts`), `src/tests/` is for global setup only
- **i18n**: Always flat keys (never nested) in `src/messages/<lang>.json`, sorted alphabetically, ICU MessageFormat, type-safe `t()` calls, `SUPPORTED_LANGUAGES` in `src/lib/config.ts`
- **Package manager**: pnpm
